A secure beginning.

Use this helper over HTTPS, or open its offline copy from the downloaded ZIP. It uses your browser’s cryptographic random generator. It sends nothing over the network, uses no libraries, and saves nothing in browser storage.

Save the generated values privately in a password manager before configuring the website. Never paste secrets into public messages or commit them to GitHub.

Do not regenerate after copying only some values: the token and token hash must come from the same generation. Keep the application key stable after installation. After setup, delete public/setup.php and clear setup_token_hash from config.php.
